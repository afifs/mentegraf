# Mentegraf Kılavuzu

Kılavuz, Mentegraf'ın kendisiyle yazılmış bir Mentegraf projesidir.

- **Okumak/düzenlemek:** Mentegraf'ta *Dosya → Aç* ile `Mentegraf-Kilavuzu/project.mentegraf` dosyasını açın.
- **Word / EPUB üretmek:** Kitap planı → **Derle ▾**. Sonuç `Mentegraf-Kilavuzu/exports/` klasörüne yazılır (git'e eklenmez).
- **Metinler:** `Mentegraf-Kilavuzu/manuscript/*.md` — düz Markdown; herhangi bir editörde de düzenlenebilir.
- **Ekran görüntüleri:** `Mentegraf-Kilavuzu/assets/` — uygulamanın açık temasından alındı; sürüm değiştikçe yenilenmeli (kılavuzun iş listesinde bir görev olarak duruyor).
