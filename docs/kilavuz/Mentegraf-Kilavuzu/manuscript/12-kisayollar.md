# Ek A — Kısayollar

## Genel

| Kısayol | İş |
|---|---|
| Ctrl+S | kaydet |
| Ctrl+Shift+S | farklı kaydet |
| Ctrl+O | aç |
| Ctrl+N | yeni proje |
| Ctrl+Z / Ctrl+Shift+Z | geri al / yinele |
| Ctrl+D | düğüm ekle |
| Delete | seçileni sil |
| Ctrl+R | otomatik düzen |
| Ctrl+0 | haritanın tamamını göster |
| Ctrl+Shift+H | metinlerde ara |
| Alt + tıklama | bağlantı kur |
| Ctrl + tıklama | çoklu seçim |

## Metin bölmesi

| Kısayol | İş |
|---|---|
| Ctrl+B / Ctrl+I | kalın / italik |
| Ctrl+K | bağlantı |
| Ctrl+Shift+F | dipnot |
| Ctrl+Shift+C | atıf |
| Ctrl+Shift+P | pasaj kimliği |
| Ctrl+Shift+G | şekil ya da tablo |
| Ctrl+Shift+K | iddia |
| Ctrl+Shift+U | soru |
| Ctrl+Shift+T | görev |
| Ctrl+E | önizleme |
